# Ncorr: 2D Digital Image Correlation (MATLAB) Chinese 汉化版

Ncorr is an open-source 2D digital image correlation (DIC) software package for MATLAB. This version includes critical updates to ensure compatibility with the WebGL-based graphics engine introduced in MATLAB R2025a, while maintaining full support for all previous versions. Not my software, just fixing a bug in the code.

本版本基于原版和ncorr_2D_matlab_2025_fix，将界面翻译成中文简体，其余功能未做修改。使用方法请参考原版链接。
已测试可在matlab R2025b版本运行。

This version is based on the original version and Hoping to fix opengl issue with 2025 version of MATLAB. The interface has been translated into simplified Chinese, while the other functions have not been modified. Compatible with MATLAB R2025b.
