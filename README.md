# Ncorr: 2D Digital Image Correlation (MATLAB) Chinese 汉化版

Ncorr 是一款开源的二维数字图像相关 MATLAB 程序。它拥有简洁直观的图形用户界面 (GUI)，采用多种新型二维 DIC 算法，完全基于 MATLAB 环境运行，并包含用于创建图形的绘图工具。计算密集型算法通过 C++/MEX 进行优化，而 GUI 则主要使用 M 代码编写。其目标是为用户提供一款易于使用、高效且灵活的 DIC 程序。

本版本基于原版和ncorr_2D_matlab_2025_fix，将界面翻译成中文简体，其余功能未做修改。使用方法请参考原版链接。请确认matlab已经安装Image Processing Toolbox和Statistics Toolbox（或Statistics and Machine Learning Toolbox），同时连接了合适的编译器。已测试可在matlab R2025b版本运行。

Ncorr is an open source 2D digital image correlation MATLAB program. It has an accessible and intuitive GUI, uses many novel 2D DIC algorithms, is wholly contained within the MATLAB environment, and contains plotting tools for figure creation. The compute intensive algorithms are optimized through the use of C++/MEX, while the GUI is written mostly in m-code. The idea is to give the users an easy to use, efficient, and flexible DIC program.

This version is based on the original version and ncorr_2D_matlab_2025_fix. The interface has been translated into simplified Chinese, while the other functions have not been modified. Make sure you have both the Image Processing Toolbox and Statistics Toolbox（or Statistics and Machine Learning Toolbox） instaled in MATLAB before trying to open Ncorr. Compatible with MATLAB R2025b.
